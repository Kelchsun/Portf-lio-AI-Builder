Kelvin de Souza Silva · Agentes de IA

Agentes que trabalham e pedem aprovação

Cada agente recebe um objetivo e um conjunto de ferramentas. O Gemini decide quais ferramentas chamar e em que ordem. Quem faz as contas e confere as regras é o código, e a entrega só é aceita se passar nessa conferência. No fim, uma pessoa aprova.

A IA decide o caminhoChama ferramentas com function calling e corrige quando é recusada.
O código faz a contaPrazos, cargas, receitas e contraste de cores nunca vêm do modelo.
A pessoa aprovaNenhuma entrega vale sem o seu "Aprovar".
Construído com Claude Code. Front-end em HTML, CSS e JavaScript; função serverless na Vercel; API do Gemini com function calling. Todos os dados são fictícios.
